# 📚 Django Local Library

A simple web-based library management system built using Django, following the official [MDN Django tutorial](https://developer.mozilla.org/en-US/docs/Learn/Server-side/Django/Tutorial_local_library_website).

## 🚀 Features

- List, view, and manage books and authors.
- Track book instances and their availability.
- Manage borrowing and returning of books.
- User authentication and permissions (librarian vs. regular users).
- Admin interface for managing all models.

---

## 🛠️ Tech Stack

- **Python 3**
- **Django 4+**
- **SQLite3** (default, easy to set up)
- **Bootstrap 5** (for basic UI styling)
